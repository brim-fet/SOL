SOL ABAYAS — GitHub Pages
1) ارفع الملفات كلها إلى مستودع GitHub.
2) تأكد أن index.html في الصفحة الرئيسية للمستودع.
3) من Settings > Pages اختر Deploy from branch ثم main / root.
4) الموقع يعمل كواجهة متجر كاملة: تصنيفات، بحث، سلة، مفضلة شكلية، تصميم متجاوب.
5) المنتجات والصور والأسعار قابلة للتعديل من script.js و assets.
6) زر إتمام الطلب حالياً تجريبي؛ يمكن لاحقاً ربطه بواتساب أو بوابة دفع وقاعدة بيانات.
